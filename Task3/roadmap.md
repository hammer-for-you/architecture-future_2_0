# Roadmap цифровой трансформации компании "Будущее 2.0" (12 месяцев)



Ниже приводится роадмап транформации в виде таблиц, сгруппированных по инициативам.



### Первое полугодие. Фундамент трансформации, первый Data Product, MVP портала

| Инициатива                                    | Ответственные                                    | Ожидаемый результат                                                                               | Бизнес-ценность                                                                                                                                                                  |
| --------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Проектирование целевой архитектуры**        | Архитектор                                       | Утвержденная архитектура Data Mesh, план миграции, стандарты разработки.                          | Снижение рисков провала трансформации, единое видение, основа для согласованной работы всех команд.                                                                              |
| **Создание платформы данных в облаке**        | Команда DevOps                                   | Развернутая и работающая платформа: Data Lakehouse, DataHub, Kafka, ClickHouse, ETL, IAM.         | **Масштабируемость:** Создана основа для работы с данными. **Снижение затрат:** Отказ от старого оборудования.                                                                   |
| **Формирование процессов управления данными** | Руководство компании, команда управления данными | Создана команда, написаны и утверждены первые регламенты по качеству, безопасности и метаданным.  | **Снижение рисков:** Основа для compliance. **Качество данных:** Стандартизированные процессы. **Снижение затрат**: Заложен фундамент для повышения эффективности работы команд. |
| **Миграция домена "Финтех"**                  | Команда домена "Финтех"                          | Данные и бизнес-логика домена "Финтех" перенесены на новую платформу. Создан первый Data Product. | **Ускорение разработки:** Финтех-направление может независимо развивать свои сервисы.                                                                                            |
| **Разработка MVP портала**                    | Фронтенд-команда, аналитики данных               | Работающая бета-версия портала самообслуживания, подключенная к данным "Финтеха".                 | **Скорость принятия решений:** Бизнес-пользователи получают первый инструмент для самостоятельной аналитики.                                                                     |



### Второе полугодие. Масштабирование, выход в production.

| Инициатива                                  | Ответственные                              | Ожидаемый результат                                                                                                                           | Бизнес-ценность                                                                                                                                    |
| ------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Масштабирование Data Mesh на все домены** | Остальные доменные команды, Команда DevOps | Все домены компании ("Медицинский", "ИИ-домен", "Корпоративный") мигрированы на новую платформу и публикуют свои Data Products.               | **Независимость подразделений:** Каждый домен развивается со своей скоростью. **Целостность данных:** Данные доступны для кросс-доменного анализа. |
| **Вывод портала в production**              | Фронтенд-команда, аналитики данных         | Полнофункциональный, отказоустойчивый портал самообслуживания с доступом ко всем Data Products.                                               | **Основная бизнес-цель достигнута:** Сотрудники могут конструировать любые отчеты в рамках своего уровня доступа.                                  |
| **Контроль архитектуры и качества**         | Архитектор, Команда управления данными     | Все разрабатываемые решения соответствуют целевой архитектуре. Регламенты по управлению данными соблюдаются.                                  | **Предсказуемость развития:** Система развивается по плану, а не хаотично. **Надежность:** Качество данных и сервисов остается высоким.            |
| **Рефакторинг и оптимизация**               | Все команды                                | Устранение  "технического долга", появившегося в ходе интенсивной разработки. Повышение производительности и снижение затрат на эксплуатацию. | **Снижение TCO:** Система становится дешевле в поддержке. **Стабильность:** Повышается отказоустойчивость сервисов.                                |
